Features

Zero Dependencies

Go standard library only. Custom YAML parser and markdown renderer built from scratch.

12-Pass Pipeline

Ordered, dependency-aware compiler passes transform the intermediate representation.

Taxonomy System

Automatic grouping, pagination, A-Z indices, and letter pages for browsable categories.

SEO Built-In

JSON-LD, Open Graph, sitemaps, RSS feeds, robots.txt, and llms.txt generated automatically.

Go Templates

60+ custom template functions built on Go html/template. Full control over output.

Fast Builds

2,000 entities compiled to 2,300+ pages in under 500ms with concurrent rendering.
